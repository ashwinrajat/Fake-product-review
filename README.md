# Review Analyzer for E-Commerce Platforms

A web application that analyzes product reviews from e-commerce platforms to help distinguish between genuine and fake reviews through automated text processing and interactive visualizations.

---

## Overview

Online marketplaces contain thousands of customer reviews, making it difficult to determine whether product feedback is authentic. This project processes review data, classifies reviews, and presents the results through a simple web interface with visual analytics.

---

## Problem Statement

Fake reviews can significantly influence purchasing decisions and reduce consumer trust.

This project demonstrates a lightweight review analysis pipeline that processes review text, classifies reviews, and presents the results through an intuitive visualization dashboard.
